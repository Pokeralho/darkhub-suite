# DarkHub Suite - User Guide

## Getting Started

### System Requirements
- Windows 10 (64-bit) or Windows 11 (64-bit)
- Administrator privileges for system configuration features

### Navigation
- **Dashboard**: Hardware overview, quick actions, and defensive status.
- **System Optimizer**: Process priority, memory management, MSI interrupts, and network tuning.
- **Advanced Security**: DNS sinkhole, URL heuristic scanner, active port sentry, and community rule importer.
- **DarkPacer**: Frame rate limiter and frametime oscilloscope HUD.
- **Gaming Low Latency**: Timer resolution and MMCSS audio scheduling.
- **Offline Utilities**: Local OCR, EXIF metadata scrubber, format converter, and encrypted password vault.
- **Settings**: Language selector, startup configuration, and manual update checker.
